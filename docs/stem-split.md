## 功能目标与适用场景

声学分轨（Acoustic Stem Split）是 Purivox 提供的无参考音频分解工作流，任务入口为 `run_stem_split_job(job, token, progress)`，图形界面分轨页与 CLI 子命令 `purivox split` 均调用该入口。

### 与深度学习分离的技术边界

声学分轨完全基于音频自身的物理声道关系与经典频域信号处理（矩阵解算与线性滤波）实现，不依赖深度学习神经网络：

- **适用场景**：适合多声道母带离散声道提取、立体声声像分析、M/S 编码处理，以及需要分轨相加能够严格在时域无损还原原始输入的母带与混音工程。具备轻量、运行快速、无模型伪影（Artifacts）且算力开销极低的特点。
- **物理局限性**：声学分轨是基于**物理空间分布**而非**语义分类**的分解。它无法在同一空间声像位置和重叠频段内区分不同乐器。例如，立体声混音中处于正中声像的独奏乐器（如萨克斯、吉他 Solo）、小军鼓的直达声以及底鼓的中高频谐波，会与主唱一同被分配至中置轨；而宽声场的立体声混响尾音、立体声合唱及宽摆位和声，则会保留在伴奏轨中。若需完全按乐器类型进行盲源分离，建议使用深度学习工具。

### 声道布局自适应分派

分轨策略严格根据输入音频的物理声道数量自适应确定：

| 声道数量 | 分派处理路径 | 输出分轨数 |
|---|---|---|
| $\ge 6$（多声道） | 离散通道提取与频域泄漏估计（`_surround_stems`） | 8 |
| 2（立体声） | 声像自适应中置提取与互补分频（`_stereo_stems`） | 6 |
| 1（单声道） | 全通互补频段分频（`_mono_stems`） | 3 |

3 至 5 声道音频因缺乏标准矩阵映射，直接截取前两声道（FL/FR）按立体声路径处理，其余声道不参与解算。

## 分轨规格清单

输出文件命名规范为 `<原文件名>_<marker>.wav`。标识符（marker）采用标准化英文标识以确保环境兼容：

### 立体声（6 轨）

| 标识符 (Marker) | 声道布局 | 信号定义与内容 |
|---|---|---|
| `center` | 单声道 | 声像自适应提取的中置信号：主唱与居中乐器 |
| `instrumental` | 立体声 | 去除中置信号后的立体声伴奏（含宽声场乐器与立体声和声/混响） |
| `side` | 单声道 | M/S 矩阵侧边信号：$(L - R) / 2$ |
| `mid` | 单声道 | M/S 矩阵中间信号：$(L + R) / 2$ |
| `low` | 立体声 | 四阶 Linkwitz-Riley 低通滤波输出（低于分频点） |
| `high` | 立体声 | 互补高通信号：$x - \text{low}$ |

### 多声道（8 轨）

包含 `surround`（后环绕 SL/SR）、`center`（中置 FC）、`lfe`（低频效果）、`front`（前置 FL/FR）、`front_no_center`（消除中置泄漏后的前置对）、`downmix`（ITU-R BS.775 标准降混立体声）、`low` 与 `high`（取自 downmix 信号的互补低高频段）。

### 单声道（3 轨）

包含 `low`、`mid_band` 与 `high` 三个互补频段分轨，三者线性相加严格还原原始信号。

## 互补分频原理与权衡

分频网络采用差分互补结构实现时域无损重构：
- 低频信号通过四阶 Linkwitz-Riley 滤波器生成（两级二阶 Butterworth 低通滤波器级联，`STAGE_ORDER = 2`）；
- 高频信号由原始输入直接减去低频信号得到：$\text{high} = x - \text{low}$。

### 设计优势与技术代价

- **优势**：在代数上严格保证 $\text{low} + \text{high} \equiv x$，两个分轨相加能够无误差还原原始音频波形，彻底消除了独立高低通滤波器在分频交叉点附近的幅频下陷与相位抵消。
- **代价与权衡**：低频信号受 IIR 滤波影响具有随频率变化的群延迟与相位旋转；高频信号因差分定义继承了互补相位响应，其单轨自身的相位并非严格线性相位。未采用零相位滤波（`sosfiltfilt`）的原因是双向滤波需要前后两趟逆向回溯计算，无法在流式分块中依靠简单的块边界状态 `zi` 连续传递。工程设计权衡优先保证“样本级精确还原与流式分块常驻内存控制”。

## 声像自适应中置分离

立体声混音的中置信号提取基于左右声道的时频相关度与能量平衡估计。在各时频单元 $(f, t)$ 上，自功率谱与互功率谱经时间平滑后定义：

$$
\psi = \frac{2\,|\Phi_{LR}|}{\Phi_{LL} + \Phi_{RR}},\qquad
\tau = \frac{\Phi_{LL} - \Phi_{RR}}{\Phi_{LL} + \Phi_{RR}}
$$

其中 $\psi \in [0, 1]$ 度量左右声道间的归一化相干度，$\tau \in [-1, 1]$ 度量能量偏向声像位置（$\tau = 0$ 对应居中声像）。

中置提取权重 $w(f, t)$ 计算如下：

$$
w = \frac{2\psi}{1 + \psi} \cdot \exp\!\left(-\frac{1}{2}\left|\frac{\tau}{\sigma_{\text{pan}}}\right|^{p}\right) \cdot g(f)
$$

1. **相干增益项**：$\frac{2\psi}{1 + \psi}$ 针对和信号 $M = (L+R)/2$ 的非相关噪声分摊特性进行了无偏修正，相较于直接使用 $\psi$ 提高了低相干声场下的中心源提取能力；
2. **广义高斯声像窗**：参数选取 $\sigma_{\text{pan}} = 0.40$（`PAN_WIDTH`）与阶数 $p = 8$（`PAN_ORDER`）。高阶超高斯窗具有平坦通带与陡峭滚降特性，在允许主唱位置存在轻微偏心（$\pm 15\%$）的同时，有效抑制大摆位侧边伴奏乐器的渗入；
3. **低频保护项**：低频加权因子 $g(f)$ 在 100 Hz 以下为 0（`BASS_PROTECT_HZ`），在 100～200 Hz 线性过渡至 1（`BASS_PROTECT_EDGE_HZ`），防止居中的底鼓与贝斯基频被误提取至中置轨。需要注意，虽然基频得到保护，底鼓的中高频瞬态击打与贝斯的高次谐波仍有一部分处于中置带宽内。

中置轨与伴奏轨通过复数谱相减生成：

$$
\text{center} = w\,M,\qquad
\text{instrumental}_{L} = L - w\,t_{L}\,M,\qquad
\text{instrumental}_{R} = R - w\,t_{R}\,M
$$

其中 $t_L, t_R$ 为按声道能量加权的比例系数，保证左右声道按实际声像位置分摊扣除，满足伴奏与中置的线性分解一致性。

长音频处理按约 45 秒分块、重叠 $\ge 2$ 秒计算，块间采用 $\cos^2/\sin^2$ 交叉平滑淡化。

## 前置声道中置泄漏消除

在多声道母带中，前置声道（FL/FR）常包含中心声道（FC）的声学串扰与母带重放残留。系统通过两遍式扫描估计逐频点的全曲复数传递系数 $\alpha(f)$：

$$
\alpha_L(f) = \frac{\sum_t F_L \overline{F_C}}{\sum_t |F_C|^2 + \lambda \max_f \sum_t |F_C|^2}
$$

其中正则化底限参数 $\lambda = 10^{-6}$（`TRANSFER_FLOOR`）基于全频带最大能量设置相对下限，防止除数过小引起增益发散。

- **不设相干度门限的原因**：前置声道自身携带大能量的立体声配器，即使中置泄漏完全线性相干，互功率谱的归一化相干度也会被前置声道自身的独立能量大幅稀释。若引入相干度门限，会导致伴奏复杂的频点处泄漏无法被消除。
- **时不变假设局限**：全曲标量传递系数基于线性时不变（LTI）声学串扰假设。对于在混音中应用了动态声像自动化移动（Dynamic Panning Automation）的前置声道，静态传递估计无法跟踪时变参数。

## 分组增益与削波保护

为保证互补分轨线性相加仍等于原信号，具有分解还原关系的分轨组共用统一的峰值归一化增益（`fit_group()`）：

1. **成组分轨**：`center` 与 `instrumental`、互补频段分轨（`low` 与 `high`）、单声道三频段轨，以及多声道 `downmix` 及其派生频段轨。
2. **分组缩放**：整组分轨渲染完成后统一测量组内最大峰值电平。若最大峰值超过 1.0，整组统一应用相同的衰减系数；若未超限则均保持原始电平输出。避免单轨独立归一化破坏相互之间的相对电平平衡。
3. **独立分轨**：不具备线性相加关系的离散声道与 M/S 信号保持原始物理电平导出，受 `export_audio()` 的削波检测保护。
4. **多声道降混缩放**：ITU-R BS.775 降混时三声道相加理论峰值可达 2.41 倍，系统先根据实测各声道峰值计算 `downmix_gain()`，再纳入分组规则。

## 评测指标与局限说明

算法性能验证基于确定性合成测试集（`tools/eval_stems.py`），支持前后基线对比：

```bash
uv run --locked python tools/eval_stems.py --save baseline.json
uv run --locked python tools/eval_stems.py --compare baseline.json
```

核心指标定义：
- `lead_removed_db`：主唱在中置剥离后在伴奏轨中的电平衰减幅度（数值越负越好）；
- `lead_kept_db`：主唱在中置轨中的保留完整度（接近 0 dB 为佳）；
- `arrangement_kept_db` / `bass_kept_db`：伴奏配器与低音成分在伴奏轨中的保留度；
- `centre_leak_db`：前置声道中置串扰消除深度；
- `band_rmse`：互补频段相加还原的波形均方根误差。

测试集指标基于理想已知信号投影计算，用于防范代码改动引入算法退化，不能作为真实商业混音试听表现的唯一结论。
