[项目首页](../README.md)。流程图用 Mermaid 绘制，数学公式用 LaTeX 编写。

## 阅读建议

- 想了解一个任务如何经过 GUI、后台线程和处理管线：先阅读“架构与数据流”。
- 想调整垫音消除效果：阅读“参考对消”，并优先检查对齐，而不是一味提高强度。
- 想修改音源匹配与自动排布：阅读“音源匹配、时间线与分段渲染”，并对照架构文档中“一条管线，两个引擎”的
  引擎选择规则。
- 想改分轨的分离效果：阅读“声学分轨”，并用 `tools/eval_stems.py --compare` 给出改动的数字。
- 准备提交代码或构建发布包：阅读“开发与贡献”。

文档内容以当前的 Python 实现为准。合成场景的回归结果不构成对真实音乐质量的结论。
