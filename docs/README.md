# Purivox 技术文档

本目录记录 Purivox 的系统架构设计、核心数字信号处理（DSP）算法原理与工程开发规范。普通用户的安装与使用指南请参阅 [项目首页](../README.md)。

## 阅读导引

- **系统实现与生命周期**：查阅[架构与数据流](architecture.md)，了解 GUI、CLI、工作线程与底层计算管线之间的调用交互。
- **算法细节与对消质量**：查阅[参考对消](reference-removal.md)，了解频域复数相减、自适应门限及泄漏回归模型。
- **多音源匹配机制**：查阅[音源匹配、时间线与分段渲染](matching.md)，了解指纹提取、互相关搜索以及几何引擎选择规则。
- **无参考分轨算法**：查阅[声学分轨](stem-split.md)，了解互补滤波相位特性与自适应声像分布加权公式。
- **浏览器端部署适配**：查阅[浏览器版（WebAssembly）](web.md)，了解 Emscripten 内存模型与静态部署要求。
- **贡献代码与发布验证**：查阅[开发与贡献](CONTRIBUTING.md)，遵循质量门禁、测试契约与提交规范。

> 文档描述以当前仓库代码实现为准。文中所引用的合成测试指标用于验证算法在确定性输入下的无损性与抗退化能力，实际处理质量以现场音频素材的真实听感为准。
